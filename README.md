# 📊 College Student Performance Dashboard

An interactive College Student Performance Dashboard developed using **Python, Pandas and Matplotlib** to analyze and visualize student academic performance.

## 🎯 Project Objective

The objective of this project is to transform student performance data into meaningful visual insights. The dashboard helps analyze factors such as attendance, marks, GPA, study hours and assignment completion.

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Excel
- Python IDLE

## 📌 Dashboard Features

The dashboard includes:

- Student-wise performance analysis
- Semester-based filtering
- Student selection
- Attendance range filtering
- KPI cards for key performance indicators
- Subject-wise marks analysis
- Attendance vs GPA analysis
- Study Hours vs Average Marks analysis
- Grade distribution

## 📈 Visualizations

The dashboard contains four main visualizations:

### 1. Subject-wise Average Marks
Compares average marks across different subjects.

### 2. Attendance vs GPA
Shows the relationship between student attendance and GPA.

### 3. Study Hours vs Average Marks
Helps understand the relationship between study time and academic performance.

### 4. Grade Distribution
Shows the distribution of grades among students.

## 📊 Key Performance Indicators

The dashboard displays:

- **Total Students**
- **Average Attendance**
- **Average Marks**
- **Average GPA**

## 📁 Dataset

The dataset contains student-level academic information including:

- Financial Management
